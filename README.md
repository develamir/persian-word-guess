# حدس کلمه فارسی
این یک بازی حدس کلمه سرگرم‌کننده با متن فارسی است. هدف: با حدس حروف یک کلمه پنهان، آن را پیدا کنید.
## نحوه بازی
1. یک حرف وارد کنید و روی **حدس بزن** کلیک کنید.
2. حروف صحیح نمایش داده می‌شوند، حروف نادرست شمارش می‌شوند.
3. اگر همه حروف را حدس بزنید، برنده می‌شوید؛ در غیر این صورت، پس از ۶ حدس نادرست بازی را ببازید.
4. روی **شروع مجدد** کلیک کنید تا بازی جدیدی شروع شود.
## نکات
- فقط یک حرف فارسی/Arabic وارد کنید.
- بازی به صورت خودکار ذخیره نمی‌شود؛ برای ادامه بازی مجدداً بارگذاری کنید.
نسخه ۱.۰
